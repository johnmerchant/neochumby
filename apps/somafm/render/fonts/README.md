# Fonts

render.py draws the screen with these open fonts, the ones neochumby-classic
bundles, so it comes out the same on any machine. They're used only to make
the pictures in `files/`; nothing on the Chumby reads them.

| File | Stands in for | Source | Licence |
|---|---|---|---|
| `DejaVuSans.ttf`, `DejaVuSans-Bold.ttf` | Verdana, Verdana Bold | Debian `fonts-dejavu-core` 2.37-8 | Bitstream Vera licence and public domain (`licenses/DejaVu.txt`) |
| `SNPro-Bold.otf` | Arial Rounded Bold | Debian `fonts-sn-pro` 1.1.0-1 | SIL OFL 1.1, with a Reserved Font Name (`licenses/SNPro.txt`) |

The licence files are the Debian packages' `copyright` files. Both licences
allow bundling the fonts with a program and drawing pictures with them.
